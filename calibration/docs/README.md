# 相机标定项目文件说明

## 主要算法模块

### 1. backPrjct.py  
- **功能**: 反投影算法，将图像坐标转换为3D世界坐标或F6变换参数
- **测试**: backPrjctTest.py
- **说明**: 核心算法，提供backproject()和backproject_to_F6()两种输出模式

### 2. selfClbr.py
- **功能**: 自标定算法，基于平移距离优化像深值
- **测试**: selfClbrTest.py
- **说明**: 在厂家FOV范围内用二分法寻找精确像深

### 3. utils.py
- **功能**: 公用工具函数库
- **内容**: 几何变换、坐标转换、验证函数等通用功能

## 文件命名规则

```
主程序.py → 主程序Test.py
```

例如：
- `backPrjct.py` → `backPrjctTest.py`
- `selfClbr.py` → `selfClbrTest.py`
- `utils.py` → 公用函数库（无独立测试）

## 核心算法流程

### 内方位参数标定
1. **像深计算** (`calc_image_depth()` in `utils.py`)
   - 输入: FOV (度), 图像宽度 (像素)
   - 输出: 像深 (像素)
   - 公式: `id = (width/2) / tan(fov/2)`

2. **自标定** (`selfClbr.py`)
   - 输入: 观测对, 厂家FOV, 搜索范围
   - 输出: 精确像深, 优化后FOV
   - 原理: 基于平移距离验证的像深优化

### 畸变校正
3. **射线重定向** (网格标定)
   - 目标: 将广角图像线性化
   - 方法: M×N正方形网格标定板建立映照关系
   - 原理: 通过重新分配像素位置来校正射线方向
   - 效果: 畸变图像 → 理想透视图像
   
   **实现细节** (dstrtCrrct.py):
   - **标定过程**: 
     - 拍摄M×N网格标定板（如16×20圆点阵列）
     - 提取畸变图像中的网格点坐标(x,y)
     - 生成对应的理想网格坐标(u,v)
     - 建立(x,y)→(u,v)的映射表
   - **UV空间设计**:
     - UV网格间距可自由设定（如30×25或50×50像素）
     - 与物理尺寸解耦，实现度量分离
     - 间距选择原则：平衡分辨率利用和插值精度
   - **鲁棒性特点**:
     - 对标定板位置要求不苛刻（目测居中即可）
     - 自动适应标定板的偏移和倾斜
     - 局部线性化处理，全局姿态不影响局部畸变校正
   - **插值方法**: scipy.griddata散点插值

### 外方位参数标定
4. **反投影算法** (`backPrjct.py`) 
   - 输入: 三角形图像坐标, 像深
   - 输出: 3D世界坐标 (mm) 或 F6变换参数
   - 功能: `backproject()` 输出3D坐标，`backproject_to_F6()` 直接输出外方位参数

### 双目立体视觉
5. **立体标定**
   - 相机A: `f6_A0 = backproject_to_F6(A_imgs, id_A)`
   - 相机B: `f6_B0 = backproject_to_F6(B_imgs, id_B)` 
   - 相对变换: `f6_AB = combine_F6(f6_A0, invF6(f6_B0))`

6. **3D重建**
   - 同名点匹配 → 畸变校正 → 反投影 → 坐标变换 → 三角化

## 技术特色

### 核心创新
- **单参数内方位**: 仅用一个实数`id`代替复杂的内参矩阵
- **自标定算法**: 基于物理测量平移距离的内参优化
- **射线重定向**: 畸变校正的本质理解，将图像校正代替镜头参数
- **一步到位**: `backproject_to_F6()`直接从图像生成外方位参数

### 设计哲学
- **问题分解**: 光学问题(畸变) + 几何问题(投影) 分离处理
- **算法简化**: 避免复杂的非线性优化，保持数学模型简洁
- **工程实用**: 用软件算法精度补偿硬件成本限制

### 广角相机处理
- **映照表方案**: M×N网格建立逐像素校正映射
- **局部线性化**: 微积分思想，小区域内弧线当直线处理
- **量身定制**: 每次标定产生专用映照表，无需通用性
