# 相机标定项目上下文文档

## 项目背景
- **应用场景**: 快速运动目标的3D测量和监控
- **技术路线**: 广角镜头 + 畸变校正（PTZ方案因响应速度慢被否决）
- **核心创新**: 基于平移距离的自标定算法
- **实现基础**: 用户有C语言实现的丰富经验，Python版本用于概念验证

## 核心技术架构

### 1. 内方位参数
- **参数**: 单一实数 `id`（像深，Image Depth）
- **定义**: 从相机原点到成像平面的像素距离
- **计算公式**: `id = (width/2) / tan(fov/2)`
- **标定方法**: 自标定算法，基于平移距离验证

### 2. 外方位参数
- **参数**: 6维向量 `F6`（位置3个 + 姿态3个）
- **作用**: 建立相机坐标系与世界坐标系的关系
- **标定方法**: 使用正三角形靶标测量

### 3. 畸变处理策略
- **核心思想**: 图像畸变校正取代镜头畸变参数
- **实现方法**: M×N正方形网格标定板建立映照关系
- **数学原理**: 微积分思想，局部线性化处理
- **物理本质**: 射线重定向，校正光路方向

## 算法模块

### 1. 反投影算法 (backPrjct.py)
- **功能**: 2D图像坐标 → 3D世界坐标
- **输入**: 正三角形三个顶点图像坐标 + 像深id
- **输出**: 3D世界坐标（毫米）
- **约束**: 50mm边长的等边三角形
- **方法**: 迭代优化，最小化边长极差

### 2. 自标定算法 (selfClbr.py)
- **核心原理**: 利用物理测量的平移距离作为真值
- **输入**: 两个位置的观测对 + 厂家FOV范围 + 实际平移距离
- **方法**: 二分法在指定范围内寻找最优像深
- **关键要求**: 实际平移**必须包含纵深成分**（Z方向变化）
- **精度**: FOV误差可达0.02°，像深误差0.68像素

## 重要设计决策

### 1. 为什么选择单一id参数？
- 简化数学模型，避免复杂的畸变参数
- 降低硬件成本（定焦镜头）
- 通过自标定算法确保精度

### 2. 为什么用图像校正代替畸变参数？
- 保持线性透视模型的简洁性
- 分离光学问题和几何问题
- 避免复杂的非线性优化

### 3. 网格映照的量身定制特性
- 每次标定的映照表都是独特的
- 不需要通用性，只为当前系统服务
- 只有精度损失，没有原理偏差

## 系统完整流程

### 单相机测量
```
原始图像 → [网格映照畸变校正] → 校正图像 → [反投影+id] → 相机坐标 → [F6变换] → 世界坐标
```

### 双目立体视觉
```
1. 两相机分别完成: id标定 + 网格标定
2. 用正三角形靶标标定两相机的F6参数
3. 同名点匹配 → 畸变校正 → 反投影 → 坐标变换 → 射线交汇 → 3D坐标
```

### 相机网络
- 多个广角相机构成mesh网络
- 每个相机观察两个正三角形靶标
- 任意两个相机观测到的质点都可计算3D坐标
- 实现大范围空间的3D监控

## 技术优势
1. **数学模型简洁**: 避免复杂畸变参数

## 关键术语解释
- **像深(id)**: 相机原点到成像平面的像素距离
- **自标定**: 基于平移距离验证的内参标定方法
- **射线重定向**: 畸变校正的物理本质
- **量身定制映照表**: 每次标定产生的专用畸变校正参数
- **F6**: 6维外方位参数向量（3个位置+3个姿态）

1. 自标定测试数据必须包含纵深成分
