## 🔧 快速上手信息

### 如何运行测试
```bash
cd calibration/tests
python3 backPrjctTest.py  # 反投影测试
python3 selfClbrTest.py   # 自标定测试
```

### 如何生成数据
```bash
cd calibration/tools
python3 saveParam.py           # 生成标定参数
python3 save_mapping_table.py  # 生成映射表  
python3 verify_points.py       # 验证并生成数组
```

### 核心算法位置
- **反投影**: `src/backPrjct.py`
- **自标定**: `src/selfClbr.py`  
- **畸变校正**: `src/dstrtCrrct.py`
- **工具函数**: `src/utils.py`

## ⚠️ 重要约束和注意事项

### 技术约束
- 自标定算法要求平移包含纵深成分
- 标定板规格: 16x20圆点, 50mm三角形
- 图像格式: 支持JPG/PNG

### 代码约束  
- 所有相对路径已修正为 `../` 格式
- Python导入使用 `sys.path.append()` 方式
- 数据文件可删除重新生成
